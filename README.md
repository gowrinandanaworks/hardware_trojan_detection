# Secure VLSI Hardware Trojan Detection

A final-year project exploring hardware Trojan detection in integrated circuits using RTL analysis, simulation, and machine learning.

## Overview

Hardware Trojans are malicious modifications to a hardware design that can affect its functionality, reliability, or security. This project investigates a workflow for identifying suspicious behaviour in RTL designs.

## Objectives

- Study clean and Trojan-infected RTL designs.
- Simulate designs using Verilog testbenches.
- Explore waveform-based feature extraction.
- Investigate machine-learning-based classification.
- Evaluate detection performance using appropriate metrics.

## Methodology

1. Develop or prepare clean and Trojan-infected RTL designs.
2. Simulate the designs and collect relevant outputs.
3. Extract features from the available simulation data.
4. Train and evaluate a machine-learning classifier.
5. Analyse the results and identify limitations.

## Tools and Technologies

- Verilog HDL
- Icarus Verilog
- Python
- Machine Learning
- Waveform Analysis

## Repository Structure

The repository will be organized as implementation files and results become available.

- `rtl/` — RTL source designs
- `testbench/` — Verilog testbenches
- `simulation/` — Simulation scripts and instructions
- `ml/` — Feature extraction and classification code
- `results/` — Evaluation results and plots
